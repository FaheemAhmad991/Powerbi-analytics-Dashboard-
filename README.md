## 🔍 Overview ##
This dashboard provides business insights from a ridesharing dataset including revenue analysis, ride patterns, cancellation trends and platform analytics.

## 📋 Dashboard Pages ##

Admin Dashboard → Total rides, revenue, drivers and riders KPIs
Revenue Analysis → Revenue by driver, vehicle type, payment type and surge zone
Ride Analysis → Peak hours, top pickup/dropoff locations and OS platform
Cancellation Analysis → Cancellation reasons, ride status and driver ratings


## 🛠️ Tech Stack ##

Power BI → Dashboard creation
Databricks → Data source
Delta Lake → Data storage
